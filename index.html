Privacy Policy - TabFlow Sessions

Last updated: September 19, 2026

TabFlow Sessions is a browser extension that helps users save, close, restore, search, and export temporary tab sessions, including automatic local restore points.

Data Stored By The Extension

TabFlow stores saved tab sessions, templates, settings, and automatic restore points locally in the user's browser using chrome.storage.local.

Saved session data may include:

  • tab titles;
  • tab URLs;
  • tab domains;
  • favicon URLs when available;
  • session names;
  • session creation dates;
  • extension settings such as language, RAM Sleep, and auto-save preferences.

Data Sharing

TabFlow does not sell user browsing data.

TabFlow does not send saved tab sessions to a TabFlow-owned server.

Payments

Premium payments, trials, login state, and free users are handled by ExtensionPay.

When users interact with Premium, ExtensionPay may process payment-related data such as email address, payment status, trial status, and Stripe checkout information according to ExtensionPay and Stripe policies.

Optional donations are handled by Stripe through a Stripe Payment Link.

Permissions

TabFlow requests browser permissions only to provide its features:

  • tabs: to read current tabs, save tab URLs/titles, close captured tabs, restore saved sessions, and discard inactive tabs.
  • storage: to save sessions, templates, settings, and restore points locally.
  • sidePanel: to display the TabFlow interface in Chrome's side panel.
  • alarms: to periodically check inactive tabs for RAM Sleep and create enabled local auto-save points.
  • https://extensionpay.com/*: to support Premium login, trial, and payment flows.

User Control

Users can delete saved sessions and restore points inside the extension.

Users can uninstall the extension at any time to remove locally stored extension data from Chrome.
